# 14 AI Gateway

## 学习位置

第三层：**Agent 基础设施**。这是连接 Agent 与多模型供应商的网关层。

## 这个模块学什么

- 模型路由、限流、降级、Fallback
- 成本控制、安全策略与网关职责
- 为什么生产环境不建议让业务 Agent 直连模型 API

## 关键文件

- `main.py` — AI Gateway / Router 演示
- `requirements.txt` — Python 依赖

## 运行

```bash
cd 14_ai_gateway
uv venv && source .venv/bin/activate
uv pip install -r requirements.txt
python main.py
```
