# 06 Agentic Coding

## 学习位置

第二层：**Agent 核心模式**。适合在理解 Tool Loop 后学习“代码 Agent”这一类特殊 Agent。

## 这个模块学什么

- 代码 Agent 的感知、规划、编辑、验证循环
- 文件编辑、测试执行与上下文筛选
- 自主编程 Agent 的能力边界与代价

## 关键文件

- `main.py` — 代码 Agent 原理演示
- `requirements.txt` — Python 依赖

## 运行

```bash
cd 06_agentic_coding
uv venv && source .venv/bin/activate
uv pip install -r requirements.txt
python main.py
```

## 学完应掌握

- 能理解编程 Agent 为什么需要额外的上下文工程和验证环节
- 能把 IDE 内 Agent、终端 Agent、自主 Agent 区分开
